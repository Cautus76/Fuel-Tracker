# Fuel Tracker

Fuel Tracker is a free and open-source Android application for recording fuel purchases, mileage, fuel costs, and average fuel consumption.

## English

Fuel Tracker is a free and open-source Android application for recording fuel purchases, mileage, fuel costs, and average fuel consumption.

The application is designed for drivers who want a simple overview of their vehicle’s fuel usage and operating expenses.

### Features

- Record fuel purchases
- Enter odometer readings
- Track fuel quantities in litres
- Track total fuel costs
- Calculate the price per litre
- Calculate average fuel consumption
- View fuel purchase history
- Store records locally on the device
- Simple and clear user interface

### Supported languages

- Czech
- English
- German
- Spanish

### Price

Fuel Tracker is available free of charge.

### Development

The application was created with the assistance of artificial intelligence in Google AI Studio. The generated code and functionality were reviewed and adjusted by the project author.

Fuel Tracker is an independent project and is not an official Google product.

### Technology

- Kotlin
- Jetpack Compose
- Material 3
- Android

### Project status

The application is currently under development. Features and user interface elements may change in future versions.

### Privacy

Fuel Tracker stores fuel records locally on the user’s device. No registration or internet connection is required for normal use.

Cloud synchronization may be added in a future version.
